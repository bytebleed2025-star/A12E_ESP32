A12E Scale Monitor — customer package
=====================================

Send these files to the customer:

1. A12E_SCALE_MONITOR_3H_TRIAL_CLOUD_FACTORY.bin
   - Complete ESP32 factory image
   - Flash at offset 0x0
   - Erase flash first (fresh 3-hour trial)
   - SHA256: F16F2A7CA1F4F48DCEDCF50F54B18F92CC87729D390D5FAA9D6269420C13125C

2. SETUP_GUIDE.html
   - Open in a browser and use "Print / Save as PDF" if you want to send a PDF.

3. GoogleSheets_Code.gs (optional)
   - Only needed if the customer wants Google Sheets logging.

Do NOT send:
- the source code / PlatformIO project
- esp32_min_web/tools/license_private.pem
- license-server/ (your activation site)
- .pio/ build folders or .dev.vars / .admin-credentials.txt
