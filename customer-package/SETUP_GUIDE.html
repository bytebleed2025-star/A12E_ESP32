3. Flash the firmware

Erasing does not reset the trial. It gives a clean install and removes old settings, but the trial token is claimed once per Device ID from the A12E license server.

Option A â€” ESP Flash Download Tool (Windows)

1

3

Set the flash options:

4

Click Add, choose the .bin, and set the offset to 0x0.

5

Select the correct COM port, click START, and wait for FINISH.

6

Press the EN/RST button on the board once.

Option B â€” esptool (Windows/macOS/Linux)

# Replace COM3 with your port (Windows) or /dev/ttyUSB0 (Linux/macOS)
esptool.py --chip esp32 --port COM3 erase_flash
esptool.py --chip esp32 --port COM3 --baud 921600 write_flash 0x0 A12E_SCALE_MONITOR_3H_TRIAL_CLOUD_FACTORY.bin

If the board is not detected:

  1. Hold BOOT/IO0.
  2. Press and release EN/RST.
  3. Release BOOT.
  4. Run the command again.

If upload fails at 921600, use --baud 115200.

USB cable and driver Use a data cable, not a charge-only cable. If no COM port appears, install the USB-serial driver for your board.

4. Connect the scale

Connect the scale/display RS232 output through a MAX232 level shifter:

Serial format: 9600 baud, 8N1.

Never connect RS232 voltage levels directly to the ESP32. RS232 can be Â±12 V and will damage the board. Use a MAX232 (or equivalent).

6. Optional â€” upload to Google Sheets

The board keeps its own WiFi AP and can connect to your router at the same time. The ESP32 uploads the data; your phone does not get internet through the ESP32.

2.4 GHz only ESP32 cannot connect to 5 GHz WiFi. Use a 2.4 GHz network.

6.1 Create the Google Sheet

  1. Open https://sheets.new and name it (e.g. A12E Scale Data).
  2. In the sheet: Extensions → Apps Script.
  3. Delete the default code and paste the contents of GoogleSheets_Code.gs.
  4. Change const TOKEN to a long random string. Remember it.
  5. Save.
  6. Project Settings → Time zone → Asia/Jakarta.

6.2 Deploy the Apps Script

  1. Deploy → New deployment.
  2. Type: Web app.
  3. Description: A12E logger.
  4. Execute as: Me.
  5. Who has access: Anyone.
  6. Deploy → Authorize access.
  7. Copy the Web app URL (ends with /exec).

6.3 Configure the monitor

  1. Stay connected to A12E_SCALE_MONITOR.
  2. Open the Config tab.
  3. Under Router WiFi: press Scan or type your 2.4 GHz SSID, then enter the password.
  4. Under Google Sheets: paste the /exec URL and the same token; set the interval (e.g. 60 s).
  5. Press Save & apply.
  6. Press Send test row. A row should appear in the sheet.

The board uploads one row per interval only when the scale has a valid reading and the trial/license is active. After the trial expires, uploads pause until activation; the test row still works.

Config is AP-only The Config tab is available only while connected to the ESP32 AP (192.168.4.1). Devices on your router LAN cannot change settings.

7. Trial and activation

The trial is a one-time signed token. Claim it once: connect to A12E_SCALE_MONITOR, open http://192.168.4.1, copy the Device ID, then on mobile data open: 

https://a12e-license.esp32dev-by-shd.workers.dev/trial

Enter the Device ID, copy the long trial token, reconnect to the monitor, paste it into Trial token and press Claim trial. Erasing the flash does not create a new trial.

The trial counts powered-on time, not wall-clock time. Turning the board off pauses the countdown. When it reaches zero, the page locks and hides the weight.

9. Safety
